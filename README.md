# Blog Pendidikan - Media Pembelajaran

Blog statis untuk tugas pendidikan tentang:

- Tujuan pembelajaran
- Peran media pembelajaran
- Dampak positif dan negatif media pembelajaran
- Solusi mengatasi dampak negatif
- Referensi jurnal Indonesia

## Cara upload ke GitHub Pages

1. Buat repository baru di GitHub.
2. Upload `index.html` dan `style.css`.
3. Buka **Settings → Pages**.
4. Pada **Build and deployment**, pilih:
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/ (root)`
5. Klik **Save**.
6. Tunggu beberapa saat. GitHub akan memberikan alamat website.
