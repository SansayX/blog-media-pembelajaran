# Blog Media Pembelajaran

Website artikel statis tentang tujuan pembelajaran, peran media pembelajaran, dampak positif dan negatif, serta solusi pemanfaatan media pembelajaran di era digital.

## Struktur

- `index.html` = isi artikel
- `style.css` = desain dan responsif
- `script.js` = progress membaca dan dark mode

## Deploy

Website ini tidak membutuhkan database, Node.js, atau build command. Cukup upload ke GitHub lalu import repository tersebut ke Vercel.
